# Cosmic Collapse 🌌

Cosmic Collapse is a small space-themed puzzle game based on the classic 2048 concept. The goal is to combine tiles with the same number to create bigger numbers, eventually reaching 2048.

## How to Play

- Use the arrow keys to move the tiles.
- When two tiles with the same number collide, they merge into one.
- Each merge increases the tile's value.
- Keep combining tiles and try to reach 2048.
- The game gets harder as the board fills up, so plan your moves carefully.

## Features

- Space-themed design
- 4×4 game board
- Tile merging mechanics
- Score and best score display
- Keyboard controls
- Lightweight browser-based gameplay

## Built With

- HTML
- CSS
- JavaScript


## Goal

The aim is to reach the 2048 tile without filling up the entire board. Try to beat your own high score!
